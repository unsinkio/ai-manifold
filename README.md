# AI Manifold

AI Manifold is an exploratory, longitudinal map of the AI ecosystem,
designed to support orientation rather than evaluation.

## What this map is
- A navigational artifact
- A multi-cluster, non-hierarchical representation
- A longitudinal view of relevance by context and use

## What this map is not
- A ranking of AI tools
- A recommendation engine
- A prediction of future dominance
- A measure of quality or intelligence
